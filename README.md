**Chrono-Parcel** adalah game simulasi teks interaktif dan visual novel bertema sci-fi fiksi spekulatif. Di sini, kamu berperan sebagai kurir lintas dimensi yang bekerja untuk *Chronos Logistics*, bertugas mengantar paket-paket absurd ke berbagai era dan realitas alternatif—mulai dari Neo-Jakarta 2099 hingga Majapahit Steampunk.

Dibangun menggunakan metodologi **vibe coding** modern yang menggabungkan kreativitas naratif mendalam dengan eksplorasi frontend interaktif murni (Vanilla JS + CSS custom properties + Web Audio API).

---

## ✨ Fitur Utama

- 🎨 **Dinamika Visual & Efek Warp**: Latar belakang, palet warna, dan efek partikel otomatis berubah menyesuaikan dimensi tempat kamu berpijak.
- 💬 **Sistem Visual Novel Interaktif**: Efek teks *typewriter*, potret karakter SVG yang ekspresif, dan alur cerita bercabang yang memengaruhi statistik (Kredit, Energi, & Stabilitas Realitas).
- 🛠️ **Bengkel Kuantum & Rak Artefak**: Gunakan hasil upah shift untuk membeli upgrade permanen, pemulih energi, dan kumpulkan 5 artefak unik lintas dimensi untuk membuka *True Ending*.
- 🔊 **Immersive Soundscape**: Efek suara sintetis langsung dari browser menggunakan Web Audio API tanpa dependensi eksternal.
